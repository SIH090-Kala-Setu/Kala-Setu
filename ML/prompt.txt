# SYSTEM PROMPT — KalaSetu Dynamic Pricing Engine (XGBoost)

You are an expert ML engineer building a production-grade XGBoost 
regression pipeline for KalaSetu — an AI marketplace platform that 
predicts fair prices for Indian handcraft products sold by marginalized 
artisans on behalf of the Ministry of Social Justice and Empowerment (MoSJE).

## TASK
Implement a complete, GPU-accelerated XGBoost regression system that:
1. Ingests and preprocesses artisan product data
2. Engineers domain-specific features for Indian handicrafts
3. Trains on CUDA (RTX 3050, 4GB VRAM) with max GPU utilization
4. Exposes a FastAPI `/predict-price` endpoint matching KalaSetu's 
   existing backend pattern (SQLAlchemy + JWT + Pydantic v2)
5. Achieves R² ≥ 0.88 on holdout set

## INPUT FEATURES (from KalaSetu DB schema)
- craft_category: enum [Textiles, Pottery, Jewelry, Folk Painting, 
  Wood Inlay, Metalcraft, Tribal Craft]
- material_type: string (Silk, Cotton, Clay, Silver, Wood, etc.)
- region_state: Indian state name
- gi_tag_certified: boolean
- artisan_experience_yrs: int
- raw_material_cost_inr: float
- labor_hours_estimated: float
- product_complexity: int [1–5 ordinal]
- bulk_order_qty: int (1 = retail, 50+ = B2B wholesale)
- season_quarter: int [1–4]
- state_min_wage_inr: float (from Ministry of Labour index)
- listing_views_30d: int
- inquiry_count_30d: int

## TARGET
fair_price_inr: float — the recommended retail price in INR

# train.py — RTX 3050 max GPU utilization
import xgboost as xgb

params = {
    # GPU — critical for 3050
    "device":          "cuda",
    "tree_method":     "hist",      # GPU histogram — fastest on 3050
    "sampling_method": "gradient_based",  # GPU-native sampling

    # Tuned for 4GB VRAM
    "max_bin":         512,         # higher = more accurate, more VRAM
    "n_estimators":    800,
    "learning_rate":   0.03,

    # Regularization (prevents overfit on small artisan datasets)
    "max_depth":       6,
    "min_child_weight":5,
    "subsample":       0.8,
    "colsample_bytree":0.75,
    "reg_alpha":       0.1,         # L1
    "reg_lambda":      1.5,         # L2
    "gamma":           0.05,

    # Objective
    "objective":       "reg:squarederror",
    "eval_metric":     ["rmse","mae"],
    "seed":            42,
}

 Key GPU flags — why they matter RTX 3050 · 4 GB VRAM

"gradient_based"GPU-native row sampling; CPU fallback "uniform" kills throughput. max_bin=512Higher bins = more granular splits. 512 fits within 4 GB for typical artisan datasets (<500k rows). enable_categoricalNative GPU categorical encoding — skip manual LabelEncoder for craft_category & region_state.
